# Examples

Finished work that followed this method. Read the pull request for what was built and the linked files for how; each one states what it verified and what it did not.

## Personal site

- [jon-lange/jon-lange.github.io#10](https://github.com/jon-lange/jon-lange.github.io/pull/10): the portfolio rebuilt around one LangSpan scene made with the actual Stageshow kit, pinned by commit and compiled to static assets, with its licence kept under `third_party/stageshow/`. Five beats, Replay and Show outcome controls, a reduced-motion poster, and a Living Canvas diagram with separate desktop and phone compositions. The scene is labelled as authored illustration, not production footage. Browser checks at 1440, 390 and 358 px and an Impeccable critique (`DESIGN-REVIEW.md`) are in the pull request.
- [jon-lange/jon-lange.github.io#11](https://github.com/jon-lange/jon-lange.github.io/pull/11): a second motion pass with better-motion and better-ui. Navigation feedback capped at 140 ms, ornamental zooms and an output wipe removed, the idle cursor stopped, theme switches without a transition. A worked example of removing motion that failed the three questions.

## LangSpan

- [Langspan/langspan.github.io#12](https://github.com/Langspan/langspan.github.io/pull/12): README product cards made with the actual ChanMeng kit at a pinned commit: light and dark animated cards, motionless stills for each, fonts outlined so the SVG needs nothing external, and the kit's static validator and Chromium frame capture run in CI. `docs/readme-animation.md` there records the storyboard, the evidence the card rests on and what was not verified.
- [Langspan/LangSpan.dev#147](https://github.com/Langspan/LangSpan.dev/pull/147): the product repository's README using those cards through `picture` sources, with the compact illustration for narrow screens, labelled as an authored explanation and not live evidence.
